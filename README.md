# Музыкальная школа «Аккорд»

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

Проект представляет собой многостраничный сайт музыкальной школы «Аккорд».
На сайте можно ознакомиться с направлениями обучения, посмотреть подробную
информацию о курсах и записаться на пробное занятие.

## Структура проекта

- `index.html` — главная страница музыкальной школы;
- `catalog.html` — каталог направлений обучения;
- `product.html` — подробная информация о курсах;
- `order.html` — страница записи на пробное занятие;
- `contacts.html` — контактная информация;
- `css/style.css` — общий файл стилей;
- `js/main.js` — JavaScript для модального окна, формы и сообщений пользователю;
- `images/` — изображения музыкальных направлений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git;

## Основные страницы

### Главная страница

На главной странице представлены:

- название музыкальной школы;
- hero-блок;
- преимущества обучения;
- популярные направления;
- карточки курсов;
- блок записи на пробное занятие;
- модальное окно с формой заявки.

### Направления обучения

На странице `catalog.html` представлены:

- каталог музыкальных направлений;
- статический блок фильтров;
- карточки курсов;
- стоимость занятий;
- ссылки на подробное описание каждого курса.

### Страница курсов

На странице `product.html` размещена подробная информация о направлениях:

- гитара;
- фортепиано;
- вокал.

Для каждого направления указаны:

- описание курса;
- стоимость занятия;
- возраст ученика;
- уровень подготовки;
- формат обучения;
- продолжительность занятия;
- таблица характеристик;
- кнопка записи на пробное занятие.

### Запись на занятие

На странице `order.html` размещена форма записи на пробное занятие.

Форма содержит:

- имя;
- e-mail;
- телефон;
- выбор направления;
- желаемую дату;
- комментарий;
- согласие на обработку данных;
- кнопку отправки заявки.

После успешного заполнения формы пользователю отображается сообщение
об успешной отправке заявки.

### Контакты

На странице `contacts.html` представлены:

- адрес музыкальной школы;
- телефон;
- e-mail;
- режим работы;
- ссылка на страницу записи.

## Семантическая разметка

В проекте используются семантические HTML-теги:

- `header`;
- `nav`;
- `main`;
- `section`;
- `article`;
- `aside`;
- `footer`;
- `address`.

Карточки направлений оформлены с помощью `article`,
дополнительные информационные блоки — с помощью `aside`.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая система цветов;
- единая шкала отступов;
- переменные для скруглений;
- состояния `:hover`;
- состояния `:focus-visible`;
- состояние `:disabled`;
- внешний файл стилей `css/style.css`;
- БЭМ-именование CSS-классов.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек;
- Flexbox для кнопок формы;
- CSS Grid для сетки направлений;
- CSS Grid для каталога с фильтрами;
- CSS Grid для страницы подробного описания курса.

## Позиционирование

В проекте используется базовое CSS-позиционирование.

На странице курса контейнер изображения имеет:

`position: relative`.

Бейдж курса размещается с помощью:

`position: absolute`.

Для управления порядком отображения используется:

`z-index`.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка направлений;
- `product-card` — карточка направления;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `product-details` — подробная информация о курсе;
- `product-table` — таблица характеристик;
- `order-dialog` — модальное окно записи;
- `order-form` — форма записи;
- `button` — кнопка;
- `contacts` — контактная информация;
- `site-footer` — подвал сайта.

Также используются БЭМ-элементы и модификаторы, например:

- `site-nav__link`;
- `site-nav__link--active`;
- `product-card__title`;
- `product-card__description`;
- `product-card__price`;
- `product-card__button`;
- `product-details__badge`;
- `order-form__field`;
- `order-form__input`;
- `order-form--page`;
- `button--primary`;
- `button--secondary`.

## JavaScript

JavaScript используется для минимальной интерактивности проекта.

В `js/main.js` реализованы:

- открытие модального окна;
- закрытие модального окна;
- определение выбранного направления;
- обработка формы;
- встроенная HTML-валидация;
- вывод сообщения об успешной отправке заявки.

Основная часть проекта остаётся HTML/CSS-сайтом.
